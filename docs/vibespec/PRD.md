# 个人记账 App - 产品需求文档

## 产品目标

帮助个人用户轻松记录日常消费和收入，通过直观的分类和统计了解资金流向，培养理财意识。解决"月底不知道钱花哪了"的普遍痛点。目标不是做专业财务工具，而是做人人每天愿意打开记录的轻量记账工具。

## 目标用户

### 主要用户

- 画像: 25-35 岁上班族，有稳定收入但无记账习惯，每月底对支出无感知
- 场景: 日常消费后随手记录（吃饭、购物、交通、娱乐），月底查看消费分布
- 动机: 想知道钱花在哪、控制不必要的支出、为储蓄目标做预算
- 当前替代方案: 不记或用 Excel 手动记（太麻烦放弃）、用专业记账 app（功能太多学习成本高放弃）

### 次要用户

- 画像: 自由职业者/小商家，需要区分个人消费和经营支出
- 场景: 记录收入来源和经营成本，年终导出数据报税

## 核心场景与用户旅程

### 场景 1: 日常快速记账

- 触发: 用户刚吃完饭，想记录这笔消费
- 过程: 打开 app → 看到默认的"记一笔"入口（首屏最显眼位置）→ 输入金额 → 选择预设分类（餐饮）→ 可选备注 → 确认
- 反馈: 动画反馈记录成功，首页实时更新今日支出总额
- 完成: 记录保存，可在账单列表中查看
- 异常/边界: 金额为 0 或负数（区分收入/支出），误操作后 3 秒内可撤销，离线模式下本地存储并在联网后同步

### 场景 2: 月底查看消费报告

- 触发: 月底用户想知道这个月花了多少、花在哪
- 过程: 打开 app → 切换到"统计"tab → 看到月度总支出/收入概览 → 点击分类查看饼图 → 点击具体分类查看明细
- 反馈: 图表直观展示消费占比，对比上月数据
- 完成: 用户对当月消费结构有清晰认知
- 异常/边界: 无数据的月份显示空状态引导"开始记第一笔"，分类占比为 0% 时不显示在饼图中

## 功能需求

### P0: MVP 必做

- R1: 用户能记录一笔支出（金额、分类、日期、可选备注）
- R2: 用户能记录一笔收入（金额、来源分类、日期）
- R3: 用户能查看账单列表（按日期倒序，支持筛选月份和分类）
- R4: 用户能查看当月消费统计（总支出、分类饼图、环比变化）
- R5: 系统内置常用消费分类（餐饮、交通、购物、娱乐、住房、医疗、其他）

### P1: 应该做

- R6: 用户能自定义分类（新增、重命名、删除非系统分类）
- R7: 用户能设置月度预算，超出时收到提醒
- R8: 数据本地存储，离线可用，无需注册即可使用

### P2: 可以做

- R9: 用户能导出账单数据（CSV/PDF）
- R10: 多设备同步（iCloud/WebDAV）
- R11: 周期性账单自动记录（房租、工资等）

## 成功标准

- SC-1: 用户从打开 app 到完成一笔记账的平均时间不超过 5 秒
- SC-2: 首次使用的用户能在无引导的情况下独立完成第一笔记账
- SC-3: 月度消费报告能被用户理解（用户测试中≥80% 的人能正确解读饼图数据）
- SC-4: 用户 7 日留存率 ≥ 40%

## 不做什么

| 不做的事项 | 原因 | 何时重新考虑 |
|------------|------|--------------|
| 银行/支付自动导入账单 | 需要对接银行 API，合规复杂，v1 不做 | 用户基数 >10 万时评估 |
| 多人共享账本 | 属于家庭/团队协作场景，非 v1 核心场景 | P2 阶段根据用户反馈 |
| 投资理财功能 | 不同产品方向，保持聚焦记账 | 不考虑 |
| 社区/社交功能 | 记账是个人行为，社交增加噪音 | 不考虑 |
| 语音记账 | 技术投入大但准确率不够，体验差 | 语音识别技术成熟后 |

## 风险与未决问题

### 阻断性问题: Resolve Before Design

- 记账的"快"和"准"如何平衡？如果只记录金额不强制分类，统计就没意义；如果强制分类，记录就不快。需要在 Design 阶段通过交互方案解决。

### 延后到 Design

- 首页布局：是突出"记一笔"还是突出"今日汇总"？
- 分类选择的交互方式：列表、网格、还是智能推荐？

### 延后到 Tech

- 本地存储方案：SQLite / IndexedDB / Realm？
- 是否需要后端服务？纯本地还是云端同步？

## 假设

- A1: 目标用户每天至少产生 2-3 笔可记录的消费
- A2: 简单直观的记账体验优于功能丰富的记账工具
- A3: 用户愿意手动输入金额和选择分类
- A4: 月度统计的可视化呈现能有效帮助用户理解消费结构

## 术语表

- 账单: 单笔记账记录，包含金额、分类、日期、备注
- 分类: 消费或收入的类别标签
- 月度报告: 按月汇总的收支统计和分类占比
